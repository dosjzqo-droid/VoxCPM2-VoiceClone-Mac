🎙️ សេចក្តីណែនាំអំពីការប្រើប្រាស់ VoxCPM2 Voice Cloning Studio នៅលើ macOS (Mac)
បង្កើតឡើងដោយ៖ Csophouret Dubbing Suite
================================================================================

កញ្ចប់នេះត្រូវបានរៀបចំឡើងជាពិសេសសម្រាប់កុំព្យូទ័រ Apple Mac (macOS) ដោយមិនប៉ះពាល់
ដល់កម្មវិធីដើមនៅលើ Windows ឡើយ។

--------------------------------------------------------------------------------
📌 តម្រូវការជាមុន (Prerequisites):
--------------------------------------------------------------------------------
១. កុំព្យូទ័រ Mac (គាំទ្រទាំង macOS Intel និង Apple Silicon M1 / M2 / M3 / M4)
២. កម្មវិធី Python 3 (ប្រសិនបើមិនទាន់មាន អាចទាញយកដោយឥតគិតថ្លៃពី https://www.python.org/downloads/mac-osx/
   ឬបើក Terminal រួចវាយ: brew install python)

--------------------------------------------------------------------------------
🚀 ជំហានទី ១៖ បើកសិទ្ធិដំណើរការដំបូង (Permission Setup - ធ្វើតែម្តងគត់)
--------------------------------------------------------------------------------
នៅលើ Mac ប្រព័ន្ធសុវត្ថិភាព Gatekeeper អាចនឹងសួររកសិទ្ធិអនុញ្ញាតសម្រាប់ហ្វាល់ Script៖
១. បើកកម្មវិធី Terminal លើ Mac (ចុច Command + Space រួចវាយ "Terminal")
២. វាយពាក្យ "cd " (មានដកឃ្លាមួយ) រួចអូស Folder កម្មវិធីនេះទម្លាក់ចូល Terminal ហើយចុច Enter
៣. វាយបញ្ជាខាងក្រោមរួចចុច Enter៖
   chmod +x Run_VoiceClone_Studio_Mac.command Run_VoiceClone_Studio_Terminal.sh Build_Mac_App.sh

--------------------------------------------------------------------------------
▶️ ជំហានទី ២៖ របៀបបើកដំណើរការកម្មវិធី (Run Application)
--------------------------------------------------------------------------------
អ្នកអាចបើកតាមរបៀបណាមួយក្នុងចំណោម ២ ខាងក្រោម៖

👉 របៀបទី ១ (ងាយស្រួលបំផុត - Double Click):
   ចុចពីរដង (Double-Click) លើហ្វាល់៖
   Run_VoiceClone_Studio_Mac.command
   (ប្រព័ន្ធនឹងបើក Terminal ដោយស្វ័យប្រវត្ត ហើយរៀបចំដំណើរការផ្ទាំងកម្មវិធីភ្លាមៗ)

👉 របៀបទី ២ (តាមរយៈ Terminal):
   បើក Terminal ក្នុង Folder នេះ រួចវាយ៖
   ./Run_VoiceClone_Studio_Terminal.sh

   * សម្គាល់៖ នៅពេលបើកលើកដំបូង ប្រព័ន្ធនឹងទាញយកបណ្ណាល័យ PyQt6 និង Edge-TTS 
     ដោយស្វ័យប្រវត្តក្នុងរយៈពេលប្រហែល ១ ទៅ ២ នាទីតែម្តងគត់។ នៅលើកក្រោយៗ វានឹងបើកភ្លាមៗ!

--------------------------------------------------------------------------------
🔑 ជំហានទី ៣៖ ការបញ្ជាក់អាជ្ញាបណ្ណ (License Activation)
--------------------------------------------------------------------------------
- នៅពេលបើកដំបូង ប្រព័ន្ធនឹងបង្ហាញលេខសម្គាល់ម៉ាស៊ីន Mac របស់អ្នក (Hardware Machine ID: CMDUB-XXXX-XXXX...)
- លេខកូដនេះត្រូវបានភ្ជាប់ជាមួយ Hardware របស់ Mac ដោយផ្ទាល់ ធានាសុវត្ថិភាពខ្ពស់
- បញ្ចូលលេខកូដអាជ្ញាបណ្ណ (License Key) ដែលទទួលបានពី Admin Csophouret ដើម្បី Active ប្រើប្រាស់។

--------------------------------------------------------------------------------
🎙️ ជំហានទី ៤៖ របៀប Clone សំឡេង និងប្រើប្រាស់
--------------------------------------------------------------------------------
១. [ជ្រើសរើសសំឡេងគំរូ]: ចុចលើប៊ូតុង "រើសសំឡេងគំរូ" ដើម្បីជ្រើសរើស File .wav/.mp3 (៣ ដល់ ១០ វិនាទី)
២. [បញ្ចូលអត្ថបទ]: 
   - ផ្ទាំង "អត្ថបទធម្មតា (Plain Text)": វាយ ឬបិទភ្ជាប់ប្រយោគដែលចង់ឱ្យអាន
   - ឬផ្ទាំង "Subtitle (only SRT format)": បិទភ្ជាប់អត្ថបទ SRT ឬចុច "ផ្ទុកបញ្ចូល SRT"
៣. [មុខងារអានព័ត៌មាន]: នៅពេលជ្រើសរើស "ការអានព័ត៌មាន (News Reading)" 
   ប្រអប់ជ្រើសរើសសំឡេងនឹងបើកដោយស្វ័យប្រវត្ត មានជម្រើសសំឡេងដូចជា៖
   - សំឡេង ១ (លោក អ៊ឹម រដ្ឋា - អ្នកអានព័ត៌មានទូរទស្សន៍)
   - សំឡេង ២ (អ្នកអានព័ត៌មាន Creator)
   - សំឡេង ៣ (អ្នកស្រី គង់ សុជាតិ - អ្នកអានព័ត៌មាន TVK)
៤. [ជ្រើសរើស Cloud Colab Server ឬ AI ធម្មតា]:
   - ជម្រើសទី ១: Google Colab Server (អាចដាក់ URL Colab Cloudflare/Ngrok ជាមួយមុខងារ Multi-Account Auto-Failover)
   - ជម្រើសទី ២: សំឡេងខ្មែរ AI ធម្មតា (ពិសិដ្ឋ / ស្រីមុំ - Free មិនបាច់ Colab)
៥. [ចុចបង្កើតសំឡេង]: ចុច "ចាប់ផ្តើម Clone សំឡេង (Start Voice Clone)" 
   រួចស្តាប់សំឡេងដែលបានបង្កើត និងចុច "រក្សាទុកសំឡេង (Save Audio)"។
